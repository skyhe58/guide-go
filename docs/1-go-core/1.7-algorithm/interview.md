## 面试答题技巧

### 1. 算法面试流程

1. **理解题意**（2-3 分钟）：确认输入输出、边界条件、数据范围
2. **思路讲解**（3-5 分钟）：先说暴力解法，再优化
3. **编码实现**（10-15 分钟）：边写边解释
4. **测试验证**（2-3 分钟）：用示例数据走一遍
5. **复杂度分析**（1 分钟）：时间和空间复杂度

### 2. Go 语言算法面试注意事项

- Go 没有泛型排序函数（1.21 之前），用 `sort.Slice` 自定义排序
- Go slice 是引用类型，回溯收集结果时必须 `copy`
- Go 没有内置 `max/min` 函数（1.21 之前），需要自己写
- Go 的 `container/heap` 需要实现 5 个方法
- Go 没有 `while` 循环，用 `for` 代替

### 3. 按公司类型的面试重点

| 公司类型 | 算法面试重点 | 难度 |
|---------|------------|------|
| 大厂（字节/腾讯） | LeetCode Medium-Hard，手写排序/DP | ⭐⭐⭐⭐ |
| 中厂（B站/滴滴） | LeetCode Easy-Medium，链表/树/哈希表 | ⭐⭐⭐ |
| 创业公司 | 基础数据结构，简单算法 | ⭐⭐ |

## 刷题路线推荐

### 第一阶段：基础（1-2 周）

1. 两数之和、有效括号、反转链表
2. 二叉树遍历（前中后序 + 层序）
3. 二分查找基础
4. 爬楼梯、斐波那契

### 第二阶段：进阶（2-3 周）

1. 三数之和、无重复字符最长子串
2. LRU 缓存、字母异位词分组
3. 快排、归并排序
4. 最长递增子序列、编辑距离

### 第三阶段：冲刺（1-2 周）

1. N 皇后、全排列、子集
2. 搜索旋转排序数组
3. TopK、合并 K 个有序链表
4. 背包问题、跳跃游戏
