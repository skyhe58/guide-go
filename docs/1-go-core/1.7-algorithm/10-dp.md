# 动态规划

## 概念说明

动态规划（Dynamic Programming，DP）是一种通过将问题分解为重叠子问题来求解的算法思想。核心要素：

1. **最优子结构**：问题的最优解包含子问题的最优解
2. **重叠子问题**：子问题被重复计算
3. **状态转移方程**：定义子问题之间的递推关系

## 高频面试题

### 1. 爬楼梯（LeetCode 70）⭐ 🔥🔥🔥

```go
// climbStairs 爬楼梯
// 状态：dp[i] = 到达第 i 阶的方法数
// 转移：dp[i] = dp[i-1] + dp[i-2]（从 i-1 阶走一步或从 i-2 阶走两步）
// 时间复杂度：O(n)，空间复杂度：O(1)（优化后）
func climbStairs(n int) int {
    if n <= 2 {
        return n
    }
    prev, curr := 1, 2
    for i := 3; i <= n; i++ {
        prev, curr = curr, prev+curr
    }
    return curr
}
```

### 2. 最长递增子序列 LIS（LeetCode 300）⭐⭐⭐ 🔥🔥🔥

```go
// lengthOfLIS 最长递增子序列
// 状态：dp[i] = 以 nums[i] 结尾的最长递增子序列长度
// 转移：dp[i] = max(dp[j]+1)，其中 j < i 且 nums[j] < nums[i]
// 时间复杂度：O(n²)，空间复杂度：O(n)
func lengthOfLIS(nums []int) int {
    n := len(nums)
    if n == 0 {
        return 0
    }
    dp := make([]int, n)
    for i := range dp {
        dp[i] = 1 // 每个元素自身构成长度为 1 的子序列
    }
    maxLen := 1
    for i := 1; i < n; i++ {
        for j := 0; j < i; j++ {
            if nums[j] < nums[i] && dp[j]+1 > dp[i] {
                dp[i] = dp[j] + 1
            }
        }
        if dp[i] > maxLen {
            maxLen = dp[i]
        }
    }
    return maxLen
}
```

### 3. 0-1 背包问题

```go
// knapsack 0-1 背包
// 状态：dp[i][w] = 前 i 个物品、容量为 w 时的最大价值
// 转移：dp[i][w] = max(dp[i-1][w], dp[i-1][w-weight[i]] + value[i])
// 空间优化：一维数组，逆序遍历容量
func knapsack(weights, values []int, capacity int) int {
    dp := make([]int, capacity+1)
    for i := 0; i < len(weights); i++ {
        // 逆序遍历，确保每个物品只选一次
        for w := capacity; w >= weights[i]; w-- {
            if dp[w-weights[i]]+values[i] > dp[w] {
                dp[w] = dp[w-weights[i]] + values[i]
            }
        }
    }
    return dp[capacity]
}
```

### 4. 编辑距离（LeetCode 72）⭐⭐⭐ 🔥🔥🔥

```go
// minDistance 编辑距离
// 状态：dp[i][j] = word1[:i] 转换为 word2[:j] 的最少操作数
// 转移：
//   word1[i-1] == word2[j-1]: dp[i][j] = dp[i-1][j-1]
//   否则: dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1
func minDistance(word1, word2 string) int {
    m, n := len(word1), len(word2)
    dp := make([][]int, m+1)
    for i := range dp {
        dp[i] = make([]int, n+1)
        dp[i][0] = i // word1[:i] 转换为空串需要 i 次删除
    }
    for j := 0; j <= n; j++ {
        dp[0][j] = j // 空串转换为 word2[:j] 需要 j 次插入
    }
    for i := 1; i <= m; i++ {
        for j := 1; j <= n; j++ {
            if word1[i-1] == word2[j-1] {
                dp[i][j] = dp[i-1][j-1] // 字符相同，无需操作
            } else {
                dp[i][j] = minThree(
                    dp[i-1][j]+1,   // 删除
                    dp[i][j-1]+1,   // 插入
                    dp[i-1][j-1]+1, // 替换
                )
            }
        }
    }
    return dp[m][n]
}

func minThree(a, b, c int) int {
    if a < b {
        if a < c {
            return a
        }
        return c
    }
    if b < c {
        return b
    }
    return c
}
```

## 常见面试题

### Q1: 动态规划和贪心算法的区别？

**难度**：⭐⭐ | **频率**：🔥🔥🔥

**答题思路**：

1. DP 考虑所有子问题的最优解，贪心只考虑当前最优
2. DP 有重叠子问题，贪心没有
3. DP 一定能得到全局最优，贪心不一定

**标准答案**：

动态规划通过穷举所有子问题保证全局最优，时间复杂度通常较高；贪心算法每步选择局部最优，效率高但需要证明贪心选择性质。能用贪心解的问题一定能用 DP 解，反之不然。

**深入追问**：

- 如何判断一个问题能否用 DP 解？
- 背包问题有哪些变体？

## 常见陷阱

1. **状态定义不清**：DP 最难的是定义状态，状态定义错误会导致转移方程错误
2. **初始条件遗漏**：边界条件（dp[0]、dp[0][0]）必须正确初始化
3. **遍历顺序**：0-1 背包一维优化必须逆序遍历，完全背包正序遍历
